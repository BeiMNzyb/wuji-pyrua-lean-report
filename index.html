PyRUA-Lean × WUJI SimBench 真实闭环复现报告

本页只把 WUJI 官方 checker 的真实自主闭环结果计为本项目成功率。论文在其他基准的数字、示范轨迹和单个视频不代替本项目的分母或成功率。

评测进行中：已完成 49/120 集。以下是阶段性结果，不是最终多任务成功率；缺的实例保留在队列中，不能删除。
能力组：RGB-D + pyroki IK + 规划器视觉选点；不使用 ACT/VLA。SAM3 权重许可检查失败，因此本组没有 locate/segment。没有训练 PyRUA-Lean。

方法与架构

PyRUA-Lean 是让规划模型编写并执行持久 Python cells 的 agent 框架，不是一个已训练的机器人控制网络。本次使用固定 revision 0f8014190d645392e9da2859f087e7b200849935 的 4B 规划器，不是论文 GPT-6 Astra，也没有在 WUJI 上训练。

模型在一个 cell 中可保留局部变量、循环调用 robo、检查返回的到位误差并重试，按需 show 声明相机图像。原语在 policy 侧通过 pyroki IK 和 WUJI bridge 执行，仿真 client 逐 tick 步进 PhysX。沙箱限制导入、文件访问和调用/时间预算。规划模型、agent 运行时、基础动作原语和可选 ACT/VLA 是四层不同组件，本次第四层未启用。

公平对照是同一规划器、原语、实例、预算和后端下的 cells 与 tool-calling：前者可在一次模型回复中执行多步 Python 逻辑，后者逐工具返回结果和状态。它不是 ACT 基线，也不能证明方法在其他机器人上的论文增益。

上游资料：源码 · 新机器人接入文档。固定 PyRUA-Lean commit fdf6e870654254e2c0c891ee407313fa48bdd0f9，WUJI commit 4c02b47c92127499ab867f81a28e7b3163af50f4。

WUJI 适配与信息边界

agent 只能看到公开任务说明、三路声明 RGB-D、相机标定、本体关节和手掌末端状态。深度反投影只使用这些声明数据；不提供物体真值位姿、仿真分割 ID 或官方 checker 反馈。robo.done 不存在，模型自称成功不记分。

原语输入、坐标和单位返回与限制
state左右 7 维臂关节和 20 维手关节，rad；手掌世界位姿本体状态、当前控制步；没有任务成功标志
move_to左/右臂，世界坐标米，四元数 wxyz；默认位置容差 5 mm、旋转 0.05 radpyroki IK 后逐步执行，最多 200 步；返回 reached、位置/旋转误差、实际步数和原因
set_hand / releaseopen、pre_shape、close 或张开指定 20 维灵巧手最多 100 步，返回关节最大误差；不是 grasp 成功判定
home左/右/双臂回到 episode 初始关节位置；不是 teleport，也不重置官方成功 latch
back_project / camera_meta声明相机的像素、内参和 camera-to-world 标定深度米、世界坐标米；深度缺失或标定不可用则显式报错
show头/左腕/右腕相机只返回声明图像；本次没有 SAM3 的 locate/segment

54 维顺序为左臂 7、左手 20、右臂 7、右手 20，经名称映射到 TensorState，不能直接假定名称排序数组。单位为米/rad；基座到世界坐标和 xyzw/wxyz 均显式转换。实际 1 mm IK→54 维动作→PhysX 小运动预试：1 步，位置误差 0.0012420687180422247 m，旋转误差 0.00040060500073079737 rad；这只是原语测试，不是任务成功率。

正式协议

  • 物理：Isaac Sim 5 / PhysX；渲染：Isaac raytracing；tianji_wuji，54 个命名位置关节，100 Hz。未以 MuJoCo 结果替代本组。
  • 每种接口最多 40 次规划调用、5400 秒墙钟；任务最大步数分别为 1000、1000、3000。温度 1.0、top-p 0.95、top-k 20，模型每集清空上下文。
  • 每任务每接口 20 个不同初始实例，共 3 × 2 × 20 = 120 集。place_can_in_box 为 20 个官方 eval；另外两任务各 10 eval + 10 train 补充，不冒充 held-out。nominal 与 i000–i004 预试实例已排除。
  • 示范元数据缺少 instance_id/instance_set，因此无法证明场景与示范不重叠；不声称无重叠。规划器未在 WUJI 上训练，示范未作为动作或真值提供给 agent。
  • 启动失败、planner error、动作异常、超时均保留在分母并单列。成功只来自 client 的逐 tick 官方 latch，超时前已 latch 才计成功。每个 episode 新进程，逐集保存日志、cell/tool 事件、官方 ledger 和视频。

限制、碰撞与后续审查

  • SAM3 权重许可未通过，因此使用显式 RGB-D 基础原语，不能与 SAM3 方案比较成功率。正式组没有 ACT/VLA。
  • IK 使用 coarse self-collision 模型且 recording parity 权重为 0；真实 USD 警告、关节漂移和穿模不能仅从视频外观排除，应结合日志审查。
  • 所选任务结果不能外推到整个 WUJI。全部失败也只能说明这一固定规划器、原语和协议下未成功，不证明任务本身不可能完成。
  • 适配代码先留在独立工作区。建议审查信息边界、54 维映射、坐标变换和测试后，再在专用 worktree 提交小 PR；本次未合并。
